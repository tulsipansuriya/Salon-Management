# Salon Queue Management System
**Live demo:** https://your-vercel-url.vercel.app
**Hosted on:** Vercel (frontend) + Render (backend)

## About
A real-time bilingual (English & Gujarati) salon queue management web application built for customers, receptionists, barbers (Ravi, Amit, Imran), a waiting-area TV display, and the salon owner.

## Screens & URLs
* **Customer Home:** `/`
* **Join Queue:** `/join`
* **Live Customer Status:** `/status/:id`
* **Reception Dashboard:** `/reception`
* **Barber View:** `/barber/ravi` (also `/barber/amit`, `/barber/imran`)
* **Waiting Area TV Display:** `/display`
* **Owner Settings:** `/admin`

## Tech Stack
* **Frontend:** React, Vite, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express, SQLite, Socket.IO
